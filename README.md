# Raaz Workspace

This repository contains the Raaz product ecosystem, including the mobile app, product documentation, and admin dashboard assets.

## Structure

- `raaz_app/` - Flutter mobile application project.
- `raaz_admin_dashboard/` - Admin dashboard templates and portal assets.
- `app- ui/` - UI design and screen mockup assets for the Raaz app.
- `Raaz prd/` - Product requirement documents and planning materials.

## Notes

- The main Flutter app lives in `raaz_app`.
- Design screens and interface concepts are stored under `app- ui`.
- Product documentation is maintained in `Raaz prd`.

## Getting Started

Open the `raaz_app` folder in your IDE to work with the Flutter application.

For product planning or design review, browse the corresponding folders:
- `Raaz prd` for requirements and release planning.
- `app- ui` for UI and mockups.
- `raaz_admin_dashboard` for admin dashboard assets.
